# MELODY-MUSIC-PLAYER-
Melody is my Frontend Internship project for CodeAlpha — a browser-based music player built with HTML, CSS, and JavaScript, styled to look like Spotify. It features play/pause/skip controls, a progress bar, volume control, a live audio visualizer, and offline playback.
